######################
Python Poetry Template
######################

========
Overview
========

A template repository enabling rapid development and continuous deployment of **Custom Python Packages**.

==========
Highlights
==========

* ``GitHub Actions`` for ``Continuous Integration (CI)`` of linting, formatting, pytests, documentation quality checks, and static code analysis on all PRs
* ``GitHub Actions`` for ``Continuous Deployment (CD)`` of Python Packages to ``Artifactory`` and Sphinx docs to ``GitHub Pages`` with each merge to ``main``
* ``Makefile`` automating common Development Environment ``bash`` commands
* ``Poetry`` Package and dependency management
